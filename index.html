01 / 数字暗房

专业胶片暗房。
从反转到最终输出。

把一卷底片逐帧翻拍到同一文件夹，开启自动处理后整批导入。NextFrame 按预设逐帧分析曝光范围、反转并校色。你可以保留片基和边码，单独微调难处理的画格，再一次导出整卷。

NextFrame 全自动胶片处理工作流

NextFrame 是为 macOS 和 Windows 设计的独立胶片数字化 App。无需 Lightroom，从负片翻拍到胶片裁切、负片反转、颜色矫正和导出，都能在一处完成。

联机翻拍，扫描件自动裁切，红外＋AI 除尘，多种扫描风格，接入 Codex。

按素材选择处理流程 →下载 NextFrame

联机翻拍，拍完自动反转

连接相机，在电脑上按快门，RAW 文件直接传入 NextFrame，拍完就看到反转后的照片。

联机翻拍教程 →

全自动工作流，和重复劳动说再见

以前处理一卷胶片，光裁切就要重复 36 次。用 NextFrame，导入即可全自动处理。

NextFrame 将自动完成裁切、拉直、识别曝光范围、设定 Dmin、负片反转和填白齿孔。

查看 RAW 自动处理流程 →

一句话搞定，无需你动手

厌倦了手动处理，你可以把 NextFrame 交给 AI。告诉 Codex「帮我处理这卷胶片」，你只用检查结果。

通过 MCP，Codex 可以直接调用 NextFrame 的处理工具，省去逐项描述和反复传图所花的 token。

用 Codex 处理胶片 →

哈苏扫描件，一键拆帧

用 PS 逐张裁哈苏 FFF 文件的日子可以结束了。在 NextFrame 里右键即可一键拆帧。

需要手动裁切时，按 F 进入整条裁切模式，一次排好一卷 36 张的裁切框。

整条扫描拆帧教程 →

负片反转，正片直出

NextFrame 可以自动识别胶片类型。彩色负片、反转片、黑白片，不管是不是同一卷，都可以一起导入，按片型处理。

查看正片与黑白片处理方法 →看负片如何转成正片 →

个性化扫描风格

胶片的颜色可以标准，也可以个性。长按 S 选择颜色模式，叠加不同扫描风格，也可以载入自己的 LUT。长按 Z 即可调整强度。

设置印片与扫描 LUT →

一键式调色

调整参数时，点鼠标点到手酸？长按快捷键，就能在转盘中调色。长按 S 换色彩模式，长按 T 调白平衡，长按 Z 调 LUT 强度。

常用参数可以放进 2、3 两个自定义转盘。D、C、M、Y 四条波形也可以直接拖动。遇到偏色，先用 DCMY 吸管取中性区域，再按需要微调白平衡，移除色偏。

使用转盘和波形调色 →看偏色怎么修复 →

红外＋AI 解决灰尘问题

谁还在一颗一颗点灰尘？带红外通道的扫描件，NextFrame 用红外信息定位并清理灰尘。相机翻拍和 RGB 扫描件，交给自带的本地 AI 除尘模型。

查看除尘教程 →

让哈苏 FFF 文件有齿孔和边框

可惜，哈苏 X5 扫描时常把片边裁掉。NextFrame 可以按胶卷型号重新模拟片边，导出时为照片带上齿孔和边框。

添加模拟片基 →

胶片排序，一键添加 EXIF 信息

有时裁切完胶片顺序会乱？NextFrame 支持重新排列画格。结合 Film Notes，可以一键录入相机、胶卷、拍摄时间与地点。

整理画格和拍摄信息 →

让胶片更有仪式感

做 Contact Sheet 不求人。把一整卷排成一张印样，或选一格喜欢的照片，导出胶片 Live Photo。

导出印样与 Live Photo →

NextFrame 支持 macOS 和 Windows。你可以在官网找到安装包和使用教程。

如何全自动处理一卷 RAW 负片？

导入整卷逐帧翻拍的 RAW，自动裁切、拉直、识别曝光范围、取样片基并反转。

怎么把整条扫描拆成单张？

选择画幅，自动分帧或手动整条裁切。需要逐帧局部处理时，可使用绝对蒙版。

查看整条扫描拆帧步骤 ↗03

反转片与黑白

反转片使用原图流程；黑白负片反转后，按需要调整灰度与影调。

反转片与黑白说明 ↗
01

密度域反转的色彩科学

从胶片的密度关系出发，结合片基取样与 DCMY 控制，重建负片的色彩与明暗层次。

 02

全自动处理

导入即开始。识别画面、校正角度、反转与校色，把整卷的重复操作交给自动流程。

 03

FFF 自动裁切

从整条扫描中识别画格、创建裁切副本。整条进，逐帧出，每一张都能独立调整。

 04

多格式兼容

连接相机 RAW、DNG、TIFF 与 FFF 扫描工作流，让不同设备的底片进入同一间暗房。

 05

齿孔与留白

保留边码，填白齿孔，配合 LIVE 留边模板。胶片边缘也可以成为作品的一部分。

 06

HDR 高动态输出

从显影预览到 Ultra HDR 输出，让明亮光源与细腻层次在兼容屏幕上充分呈现。

 07

专业调色能力

DCMY、分区白平衡、曲线、混色器、色彩分级、LUT 与局部蒙版，从准确还原到个人风格。

 08

一键式调整

长按呼出转盘，直接拖拽波形，快捷键连续操作。整条裁切，让一卷照片保持同一个节奏。

 09

联机拍摄

连接支持的相机，实时取景、遥控拍摄并接收照片；也可监看文件夹，接续已有翻拍设备。

 10

红外与 RGB 除尘

有红外通道的扫描件可按缺陷标记修复。普通 RGB 图像可在本机检测全图灰尘，也可只框选一小块。

 11

LIVE 动态成片

把静态底片做成动态展示。macOS 可保存为 Live Photo，Windows 可导出 Live 视频。

 12

Agent 可用

通过本地 MCP 接入支持的 Agent，用对话调用反转、裁切与调色，也能随时接回手动编辑。
