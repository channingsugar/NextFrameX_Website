Automatic RAW mode

With automatic processing on, importing a single copied RAW runs detection, crop, and inversion from your preset. You can also run it again on a photo you already have.

Strip scans and frame splitting

Use this when one TIFF, FFF, or DNG contains several frames in a row.

Read chapter ↗05

Absolute masks on a strip

Absolute masks invert and adjust each frame on the same strip scan, then split the strip once at the end.

Read chapter ↗06

Slides and black-and-white negatives

Slides use the original-image path. Black-and-white negatives are inverted, then adjusted for gray and tone.

Read chapter ↗07

Density inversion and sampling

The inversion panel controls a negative’s brightness and color through a density-domain conversion and the DCMY settings. Exposure range, Dmin, and Dmax set the analysis area and the reference points.

Read chapter ↗08

Color

Check the analysis range first, then white balance and color cast. If the automatic result looks right, do not rebalance it.

Read chapter ↗09

Sprockets, dust, and texture

Sprocket handling when you keep the film base, plus dust removal, sharpening, glow, and grain.

Read chapter ↗10

Batch, HDR, and LIVE export

Before export, choose the photos to save, then set format, size, and output.

Keyboard shortcuts

Troubleshooting

Find the symptom, then the check that goes with it.

Connecting an agent

NextFrame exposes image tools to clients that speak local MCP. Once connected, you can name a folder, a processing path, and the changes you want in conversation.

Read chapter ↗14

File formats and tethered capture

NextFrame can process camera copies and scans. It can also connect to a supported camera, or watch a capture folder.

Dials and waveforms

The dial picks a mode or adjusts a setting quickly. Waveforms control inversion directly. The common moves can happen in the preview.
