Batch, HDR, and LIVE export

Before export, choose the photos to save, then set format, size, and output.

English guide · Updated 2026-10-17 · Interface reference 2.54.0

Copy settings across photos

Select several targets in the filmstrip, or press ⌘ A to select the current set. On the reference, press ⌘ C. Select the targets and press ⌘ V, then check the modules to sync in the paste panel.

Crop, Dmin, and exposure usually need their own settings on each picture. If a mask is selected, ⌘ A and similar commands act on masks. Leave mask selection before you batch-edit photos.

Keep more than one version

Press ⌘ D to make a virtual copy and compare different grades. A copy keeps its own edit settings. It becomes a separate image file only after export.

Still export

  1. Select the results and press ⌘ S to open export.
  2. Check the selected count. Choose JPEG, TIFF, or PNG.
  3. Set the long edge, quality or bit depth, and the color space.
  4. For ordinary web sharing, choose SDR and sRGB. For later editing, use a high-bit-depth format the app supports.
  5. Set the names and destination, click Export, and wait until it finishes.

Open the folder afterward and check count, size, and color. Failed items can be sent again with Retry.

HDR preview and output

In Develop, switch the Monitor to the HDR view. Drag the chart left or right to set HDR brightness, and hold the HDR preview button to see the result.

On export, set Dynamic Range to HDR and choose a strength: Auto, Natural, Standard, Strong, or Extreme. HDR currently uses Ultra HDR JPEG. Other formats are limited while HDR is on. Switch back to SDR before a Live export.

Check the file on a screen and in software that support HDR. Where HDR is not supported, you see the compatible SDR rendering. An ordinary web screenshot cannot show the full HDR brightness.

LIVE export

  1. Open export, set Dynamic Range to SDR, and choose the Live format.
  2. Choose the Signature, Border, or Full Bleed template. Turn on Show Logo if you want it.
  3. Choose the photos and destination, click Export, and wait for the short clip to finish.
  4. On macOS, NextFrame tries to save the Live Photo to Photos. You can AirDrop it to an iPhone from the library. Windows exports a Live video.

If macOS says Photos permission was not granted, the file may still be in the export folder. Grant access and write to the library again. The batch is not necessarily lost.

Format, size, and quota follow the current version and the account’s permissions.
