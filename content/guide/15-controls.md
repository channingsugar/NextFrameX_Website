# 转盘与波形操作

转盘用于快速选择模式或调整参数，波形用于直接控制反转。常用操作可在预览区完成。

## 长按呼出转盘

将焦点放在显影工作区，按住相应按键，移动指针选择转盘中的项目，按界面提示完成选择。短按同一按键执行另一项快捷操作。

| 长按 | 功能 |
| --- | --- |
| A | 曝光范围 预设、自动处理 |
| D | 自动裁切方式、拉直、未裁切 |
| S | 鲜明、自然、原始影调模式 |
| Q | 选择 Dmin 或 Dmax 取样 |
| T | 色温与色调 |
| G | 齿孔填色阈值 |
| Z | LUT 开关与强度 |
| 2、3 | 自定义转盘 |

在“处理偏好”中设置“自定义(2)”和“自定义(3)”的控制项。选择自己常用的调节参数后，可在编辑时长按对应数字键调用。

## 拖动波形

展开反转面板，拖动 D、C、M、Y 波形的左端或右端。左端控制基线，右端控制增益。D 调整体，C／M／Y 分别对应红、绿、蓝通道。

先小幅移动并观察画面，再继续调整。暗部和高光有不同偏色时，分别调整对应端点；不要仅为使波形重合而改变颜色。详细说明见[颜色调整](08-color.html)。

## 连续处理照片

按左右方向键切换照片，`N` 对比效果，`V` 显示标记，`F` 裁切，`⌘ C`／`⌘ V` 复制和粘贴参数，`⌘ S` 打开导出。

整条扫描进入 `F` 裁切后，选择“整条”，通过帧数、组数、间距和错位参数调整全部框。详见[整条扫描](04-strip.html)。

完整按键列表见[快捷键速查](11-shortcuts.html)。
