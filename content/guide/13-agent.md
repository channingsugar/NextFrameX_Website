# 连接 Agent

NextFrame 通过本地 MCP 向支持该协议的客户端提供图像处理工具。连接后可用对话指定目录、处理方式和修改要求。

## 配置连接

1. 打开 NextFrame，进入“设置 → Agent MCP…”。
2. 添加允许处理的素材目录，点击“启用本地 MCP”。
3. 将窗口显示的 Codex 或 Cursor 配置复制到对应客户端的 MCP 配置中。
4. 重新加载客户端工具，让 Agent 检查 NextFrame 连接状态。

配置使用本机窗口显示的路径。应用退出后需重新启用连接。NextFrame 无需填写大模型 API Key。

## 处理一个文件夹

可向 Agent 输入：

> 用 NextFrame 处理文件夹「实际素材路径」。RAW 保留片基，整条扫描移除片基。检查每帧裁切与颜色，先展示处理结果。

将引号内替换为实际路径。继续修改时，说明文件名及具体要求，例如“把 _200885.ARW 调亮一点，保留现在的色调”。

已手工调整的照片，可明确要求保留现有参数，以当前效果为基础修改。

## 网络设置

网络支持时保留云端校色。无法连接校色服务时，可说“本次关闭云端校色，继续本地处理”。Agent 客户端能联网，不代表 NextFrame 的校色服务也能连接。

## 检查与导出

查看预览，检查裁切、范围、齿孔和颜色。需要修改时继续描述要求。

当前 MCP 导出入口会打开 NextFrame 的导出窗口，由用户选择格式和目录并完成导出。导出结束后检查目标目录中的实际文件。
