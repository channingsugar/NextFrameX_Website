# Choose a workflow

Pick a path from the film type.

## Which path

| Source | Use |
| --- | --- |
| A single color negative copied with a camera | [Automatic RAW mode](03-raw.html) |
| A TIFF, FFF, or DNG that contains several frames | [Strip scans and frame splitting](04-strip.html) |
| A strip you want to grade frame by frame, then crop | [Absolute masks](05-masks.html) |
| Slide film | [Original-image path](06-positive.html) |
| Black-and-white negative | Invert, then turn on grayscale output if you want it |

File format and film type are separate questions. A DNG might be one copied frame or a whole strip. A TIFF might contain only one photo.

## Film base

Keep Base retains edge codes and sprocket holes. Remove Base keeps only the picture. Either way, crop away the light panel, scanner bed, and continuous white border outside the film. Sprocket holes filled white inside the base can stay.

## Format of a strip scan

Confirm half-frame, 135, 6×6, 6×7, or XPAN, then count the actual frames. After automatic detection, check the first frame, the last frame, and frames in between. If the spacing varies, or the strip mixes formats, adjust the crop boxes separately.
