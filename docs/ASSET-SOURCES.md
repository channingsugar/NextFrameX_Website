# 2026-10-17 网站素材来源

## 使用范围

按用户本次要求，所有照片示例仅取当前 NEX 2.54.0 的 `4879` 与 `raw` 目录。界面实际目录名是 `4879`（36 张），不是消息中首次出现的 `4897`。raw 目录有 `_200885.ARW` 与 `_201019.ARW` 两张。

通过 NextFrame MCP 读取已保存的参数和原生预览，没有重新反转、校色或修改照片。展示图仅做尺寸压缩与联系表排版。它们是当前显影预览，不宣称是刚刚执行全自动处理的前后对照或全分辨率导出。

## 首页样片

`media-manifest.json` 逐一记录 8 张首页图片的文件名、应用内 ID、排序和描述，全部来自 4879 的不同分帧副本。选择了滑翔伞、树荫海滩、沙滩影子、街头人像、鸟、舷窗、街道、海边人像，避免使用同一画格或近似连拍。

`assets/media/hero-01.webp` 至 `hero-08.webp` 取代原首页的 14 张旧作品。旧作品不再被新页面引用，也不进入 `_site` 发布目录。

## 产品和教程插图

- `workspace.webp`：2026-10-17 当前 NEX 2.54.0 显影窗口截图，raw 目录，选中 `_201019.ARW`。
- `inversion-panel.webp`：同一截图的反转控制面板局部。
- `auto.webp`：raw 目录 `_200885.ARW` 当前原生显影预览，保留片基。
- `range.webp`：同一 RAW 的原图和当前分析范围、取样点、蒙版标记。表示现有参数的位置，不是推荐所有图照抄的范围。
- `strip.webp`：仅将 4879 已分帧照片排为联系表，保持各照片原比例，不是自动分割界面的截图。

原有其他测试照片和颗粒对照图均不再进入页面或发布产物。
